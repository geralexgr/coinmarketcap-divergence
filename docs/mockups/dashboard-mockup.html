How it works

Why it is a web app and not only an agent

A judge can open a URL and check the numbers against CoinMarketCap themselves. That is what makes the largest scoring criterion, whether the thing actually works, easy to award.

Why the MCP layer comes last

Once the scores sit in a database, exposing them as agent tools is a thin wrapper over queries you have already written. Same codebase, second track.
